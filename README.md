# 💡 Smart Light Control System

A TypeScript-based smart lighting application that allows users to control and automate lighting settings in their rooms and building. The system provides a user-friendly interface for real-time control and automated light scheduling.

---

## ✅ Project Status

- ✅ **All known bugs resolved**
- ✅ **Application fully functional**
- ✅ **Core and extended features completed**

---

## 🚀 Features

### 🔦 Light Regulation
Users can adjust the **intensity** of lights for each room through intuitive slider controls. The light state (ON/OFF) automatically reflects the intensity value.

### ⏱️ Smart Light Scheduling
Set automated **presets** to control when lights turn **on** or **off** in each room. Users can define specific **start** and **end** times to automate their lighting preferences.

---

## 🧰 Technologies Used

- **TypeScript** for strict typing and scalable architecture
- **HTML/CSS** for responsive and interactive UI
- **Modular JS/TS architecture** to separate concerns (`basicSettings.ts`, `advanceSettings.ts`, etc.)
- **Local DOM Event Handling** for reactive changes
